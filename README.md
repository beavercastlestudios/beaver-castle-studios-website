# Beaver Castle Studios website

A fast, static studio website with no paid framework or CMS dependency.

## Preview locally

Run `python3 -m http.server 8000` in this folder and open `http://localhost:8000`.

## Publishing for free

Connect this repository to Cloudflare Pages or GitHub Pages. There is no build command; the publishing directory is the repository root.

## Updating the Steam link

When the Steam page is live, replace the `Coming to Steam` span in `index.html` with a link to the verified Steam store page.
